# Scoring Workflow & Matches

This guide covers how athletes and referees input and track scores during both the Qualification and Elimination rounds using the digital scoresheet.

## 1. Accessing the Scoresheet

During an active competition, authorized users (Athletes and Referees) can access the scoresheet directly from their device.

1. Navigate to the active **Competition**.
2. Depending on the current phase, select either **Qualification** or **Elimination**.
3. Find your assigned Target or Match and click **Enter Scores**.

> **Note:** Only the assigned athlete or an official event referee can input scores for a specific target.

## 2. Qualification Scoring

The Qualification view provides a digital replica of a traditional archery scorecard.

### Entering End Scores
1. The scorecard is divided into **Ends** (usually 3 or 6 arrows per end).
2. Enter the value of each arrow shot in descending order (e.g., 10, 9, 9, 8, 8, 7).
3. The system will automatically calculate the:
   - **End Total:** Sum of the arrows in the current end.
   - **Running Total:** Cumulative score for the entire round.
   - **10s and Xs:** The system automatically tallies the number of 10s and inner-10s (Xs) for tie-breaking purposes.

### Live Leaderboard
As scores are submitted end-by-end, the **Live Leaderboard** updates automatically. This allows spectators, coaches, and athletes to see real-time rankings without waiting for the end of the tournament.

## 3. Elimination Scoring (Matches)

Scoring an elimination match differs depending on the bow style (Recurve vs. Compound). The application automatically adjusts the scoring interface based on the competition rules.

### Recurve: Set System
Recurve matches use the Set System.
1. Athletes shoot sets of 3 arrows.
2. Enter the arrow values for both athletes.
3. The system calculates the set total.
   - The athlete with the higher set score receives **2 Set Points**.
   - If tied, both receive **1 Set Point**.
4. The first athlete to reach **6 Set Points** wins the match.

### Compound: Cumulative Scoring
Compound matches use cumulative scoring.
1. Athletes shoot ends of 3 arrows.
2. Enter the arrow values for both athletes.
3. The system maintains a running total.
4. After the designated number of ends (usually 5 ends, totaling 15 arrows), the athlete with the highest total score wins the match.

### Tie-Breakers (Shoot-offs)
If a match is tied at the end of regulation (e.g., 5-5 in Set Points, or 145-145 in Cumulative), the system will prompt a **Shoot-off**.
1. Each athlete shoots a single arrow.
2. Enter the score. 
3. If the scores are identical (e.g., both shoot a 10), the referee must measure the distance to the center. You can mark which arrow is closer in the system to determine the winner.
