# Event Management

This guide covers the initial creation and configuration of an archery event using the **Archery Event Management** application.

## 1. Creating a New Event

To host a new event, you must first create it through the application dashboard.

1. Navigate to the **Events** section in the main navigation bar.
2. Click the **Create Event** button.
3. Fill in the required details:
   - **Event Name:** A clear, identifiable name for your competition.
   - **Dates:** Select the start and end dates.
   - **Location:** The venue where the event will take place.
   - **Ruleset:** Define the governing rules (e.g., WA - World Archery).
4. Click **Submit** to create the event.

Once created, you will be redirected to the **Event Dashboard**, also known as the **Host Panel**.

## 2. The Host Panel

The Host Panel (`EventDetailView`) is your central control room for managing the event lifecycle. It provides several tabs to manage different aspects of your event:

### Overview
This tab displays high-level information about the event, including its status, dates, and total number of participants.

### Athletes
Before a competition can begin, athletes must be registered to the event.
- Use the **Register Athlete** action to add participants.
- You can view the list of all registered athletes, their associated teams, and their respective categories (e.g., Recurve Men, Compound Women).

### Referees
Referees are responsible for verifying scores during the event.
- Assign users with the referee role to your event.
- Only registered referees will have access to the scoring sheets during the competition.

### Host Settings
This tab provides administrative controls:
- **Edit Details:** Modify the event name, dates, or location.
- **Generate Competitions:** Based on the registered athletes, the system can automatically group them into valid competition categories.

## 3. Advancing to Competition Setup

Once all your athletes and referees are registered, and your event details are finalized, you are ready to transition to the **Competition Setup** phase. This involves scheduling the Qualification rounds and generating Elimination brackets.
